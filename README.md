# AI Biotech 转型路线图

PhD（分子生物学与生化）→ 计算生物学 / ML-literate biotech scientist。
24 周，每周 6–8 小时。定位：biology-first，能判断数据是否可信、能分析多组学证据、能支持研发决策。

## 周计划

- 第 1–8 周：底座（SQL、ML 基础、可复现工程）
- 第 9–16 周：主轴单细胞 + 副轴药物数据
- 第 17–24 周：作品集收尾、简历 2.0、面试
